## 一、方向确认

项目收缩为：**以作者知识为核心，经拆书 → 量化 → 反思 → 炼制技能 → 作者审核 → 受控执行 → 反馈，形成可验证的知识与执行系统**。

四项主线（优先级）：
1. 量化拆书
2. 反思学习
3. 受控执行智能体
4. 可扩展插件内核

原则：不给 tts/生图/同步/多智能体/任意代码执行等外围以"已完成"假象；未接入真实 provider 一律返回结构化 `DISABLED`。
