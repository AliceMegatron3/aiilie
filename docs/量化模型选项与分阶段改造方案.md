# 量化模型选项与分阶段改造方案

> 生成时间：2026-08-16。

---

## Phase 1 — 量化模型选项修复 ✅

### 根因
`agentStore.ts` 硬编码 `'deepseek-r1:7b'` / `'qwen2.5:7b'`；`GET /models/ollama` 已可嗅探本地模型但从未被调用；后端 `POST /quantize` 不接受 model 参数；设置页保存不回写 agentStore。

### 改动清单

**后端**
- `api/library.py`：`QuantizeRequest` 新增 `model: str | None = None`，透传给 quantifier
- `services/quantifier.py`：`submit_quantize_task` 接收并存储 `model`，写入 `raw_command`
- `services/dispatcher.py`：`dispatch` / `_dispatch_inner` / `_call_cloud_model` / `_call_local_model` 均增加 `model_override` 参数，运行时覆盖而不污染实例状态

**前端**
- `agentStore.ts`：移除硬编码默认值；新增 `fetchFromConfig()` action，并行调 `GET /models/ollama` + `GET /settings/llm`
- `api/index.ts`：`library.quantize` 增加可选 `model` 参数
- `LibraryPanel.vue`：量化按钮旁新增模型 `<select>` 下拉框，数据源 = 已检测模型列表；`executeQuantize` 传 model；`onMounted` 调 `fetchFromConfig()`
- `SettingsView.vue` / `SettingsPanel.vue`：Ollama 模型名从 `<input>` 改为 `<select>` 下拉 + 刷新按钮；保存时回写 agentStore

## Phase 2 — 插件安装器（替换 501） ✅

### 改动清单
- `core/plugin_lifecycle.py`：实现七态状态机 `INSTALLED→LOADING→ENABLED→RUNNING→ERROR→DISABLED→UNINSTALLED`，含合法转移表
- `core/plugin_manager.py`：新增 `install_plugin(source_path)` 支持目录或 zip；`uninstall_plugin(plugin_id)`；`list_installed_plugins()` 返回 manifest + 生命周期状态
- `api/plugins.py`：`POST /plugins/install` 接受 `source_path` 参数，调 `install_plugin`；新增 `POST /plugins/uninstall`；`GET /plugins` 返回含状态的清单
- `SystemDashboard.vue`：`installPlugin()` 改为调 `api.plugins.install(source)` 并用 `prompt()` 交互输入路径

## Phase 5 — 书库卡片真量化 + 独立卡片页 + 量化弹窗选模型 ✅

### 背景
书库量化原本走 `DefaultStrategy`（规则模拟，产出占位卡片，不调用大模型）；`LLMExtractionStrategy` 已写好但未接线；前端无卡片展示入口。

### A. 量化提取：LLM 优先 + 规则兜底
- `core/bootstrap.py`：`setup_quantification` 提前创建 `ModelDispatcher`，装配 `FallbackStrategy(primary=LLMExtractionStrategy, fallback=DefaultStrategy)`
- `strategies/extraction.py`：新增 `FallbackStrategy` 组合策略（主策略异常/空结果时回退规则）
- `config/config.yaml`：新增 `library.quantize_extraction: auto`（llm/rule/auto）
- `services/quantifier.py`：`submit_quantize_task` 接收并存储 `extraction`；新增 `_resolve_strategy()` 按任务级提取模式选择策略
- `api/library.py`：`QuantizeRequest` 新增 `extraction` 字段透传

### B. 独立卡片页（三类分标签）
- `frontend/src/router/index.ts`：新增 `/cards` 路由
- `frontend/src/components/views/CardsView.vue`：新建，三类标签（资料/数据/扩展卡），支持关键词搜索、详情弹窗、编辑、删除
- `frontend/src/api/index.ts`：新增 `updateCard`、`deleteCard`
- `api/library.py`：新增 `DELETE /library/cards/{card_id}`

### C. 量化弹窗选模型（含 API/本地）
- `frontend/src/components/QuantizeModal.vue`：新建量化设置弹窗（量化类型、模型下拉、提取方式）
- `frontend/src/components/panels/LibraryPanel.vue`：量化入口改为弹窗流程；模型列表 = 本地检测 + 云端配置
- `frontend/src/components/LeftPanel.vue`：知识组新增「卡片库」入口
- `frontend/src/stores/useAppStore.ts`：`AppModule` 新增 `cards`

### 验证
- 后端启动确认 `quantifier.strategy` = `FallbackStrategy`，内含 `LLMExtractionStrategy` + `DefaultStrategy` ✅
