# 三国类似研究 · 天时地利人和：东汉系统图谱

> **目的**：把东汉末年的自然环境、空间条件、社会关系、制度能力和人的行动放在同一张图里。天时不是“天命”，地利不是“地图背景”，人和也不是简单的“民心”；三者通过粮食、道路、户籍、兵源和权力分配发生作用。

---

## 一、总图：五层系统

### 第一层：天时

包括旱、蝗、洪水、地震、疫病、寒暖变化、牲畜疫病和季节性青黄不接。

- 直接影响：收成、饮水、牲畜、行军和疾病传播。
- 间接影响：粮价、借贷、卖地、逃亡、宗教求治和地方治安。
- 政治放大器：朝廷如何解释灾异、是否赈济、是否继续征税，会决定自然灾害是否转化为政治危机。

### 第二层：地利

包括河流、平原、山脉、关隘、道路、港口、盐井、铁矿、水利和城市位置。

- 直接影响：粮食产量、运输速度、军队机动和防御能力。
- 政治含义：控制某处不等于控制整个区域，还要能控制通道、仓储、人口和地方官吏。
- 东汉差异：益州有山川和成都平原，凉州有边地军费与骑战传统，江东有长江水网；不同区域会形成不同的政权形态。

### 第三层：人和

包括家庭、里社、豪强、佃户、部曲、奴婢、商旅、士人、宗教组织、军队和边疆部落。

- 直接影响：谁能提供粮食、信息、兵员、住宿和保护。
- 权力含义：所谓“民心”往往通过具体组织表达，如乡里互助、宗教网络、坞堡、军队和士族门生。
- 流动性：灾荒和战争会使人脱离原籍，流民不是静止的受害者，也可能成为军队、宗教组织和新政权的组成部分。

### 第四层：制度与技术

包括田租、算赋、口赋、更赋、户籍、郡县、刺史、州牧、屯田、驿传、仓储、五铢钱、纸、井盐、水利和冶铁。

- 制度负责把资源变成可征收、可调度的力量。
- 技术决定单位人力能生产多少粮食、盐、铁和文书。
- 制度失效时，豪族和军队会用私人关系接管土地、人口和仓储。

### 第五层：解释与合法性

包括天灾观、儒家政治批评、太平道、汉室正统、宗室名义、军事功劳和禅让。

- 解释不能直接制造粮食，但能让人相信某种秩序值得服从。
- 黄巾的“苍天已死”把灾害、生计和政权更替联系起来。
- 曹操奉天子、刘备称汉、孙权称帝，都是把军事实力转译为合法性。

## 二、天时：自然事件如何成为社会危机

### 2.1 旱灾与蝗灾

| 环节 | 作用 | 可观察细节 |
|---|---|---|
| 第一季 | 土壤缺水、作物受损 | 井浅、河断、田裂、麦穗空瘪 |
| 第二季 | 粮食储备消耗 | 秋粮提前吃完，种子和口粮冲突 |
| 第三季 | 市场与税役冲突 | 粮价上涨，官府仍按旧额征租征赋 |
| 第四季 | 家庭关系瓦解 | 借粮、卖地、卖身、卖儿鬻女、逃亡 |
| 第五季 | 政治动员 | 粥棚、宗教治病、流民结伙、地方武装 |

蝗灾的社会后果不只是“少收一季粮”。蝗群会破坏牧草、菜蔬和树叶，影响牲畜与下一季生产；灾民集中流动又增加疫病传播和治安压力。

**研究边界**：本项目设定的183年秋三辅—汉中交界连年旱蝗属于艺术化地方情境，应与175年三辅螟、177年七州蝗及光和年间灾疫背景合并使用，不写成一条精确的全国灾异记录。

### 2.2 疫病

疫病通过四种方式改写政治：

1. **损失人口**：死亡直接削弱家庭、军队和税户。
2. **打断流动**：驿站、军营、城市和粥棚成为传播节点，也可能被迫隔离。
3. **改变信任**：官府医药未到、祭祀无效时，民众会转向地方医者、巫祝、宗教或豪强保护。
4. **改变军事计划**：军中疫病会让一支规模很大的军队失去行动能力，退军未必是怯战。

东汉朝廷的反应常见两条线：祷祠、赦免、改元、举贤良等礼制动作，以及遣使致医药。两者都属于国家回应，但抵达地方的速度、数量和执行质量不同。

### 2.3 季节性饥饿

“青黄不接”是稳定的社会节奏：旧粮吃尽，新粮未熟。春季的饥饿尤其容易与流民、盗匪、借贷和宗教活动相连。写作时要根据当地作物、地形和交通判断饥荒时间，不把所有地方都写成同一日历。

## 三、地利：从地图到资源链

### 3.1 洛阳与关中

**洛阳的优势**：政治中心、官署密集、太学和市场集中、容易获得关东粮食和人才。

**洛阳的脆弱性**：中心城市高度依赖外围郡国；一旦道路、仓储和河运被战争切断，宫廷仍有仪式，却可能缺粮。

**关中的优势**：山河险固、长安有旧都资源、可控制关隘。

**关中的脆弱性**：人口和粮食恢复需要时间；长期军队驻扎、天子百官迁徙和地方征发会迅速消耗关中。

### 3.2 凉州、并州、幽州

这些地方不能只写为“蛮荒边疆”。它们是：

- 军马、牲畜和骑战技术的重要来源。
- 汉廷军事支出和边贸的承压区。
- 羌、鲜卑、乌桓、南匈奴与汉地郡县、屯戍、豪强的接触地。
- 军人、商旅、俘虏、部落成员和流民频繁流动的区域。

边疆冲突经常同时是土地、草场、牲畜、贸易路线、贡赋、军粮和政治名位的竞争；不能单纯解释为“民族天生敌对”。

### 3.3 汉中与益州

| 资源层 | 汉中 | 益州 |
|---|---|---|
| 空间 | 盆地与山口，北接关中，南接蜀道 | 成都平原、山地和南中广大区域 |
| 军事 | 北门、关隘、粮道、宗教组织 | 山川屏障、郡县、坞堡、州牧和地方军队 |
| 生产 | 粮食、铁、连接南北的交通 | 粮食、水利、井盐、铁、蜀锦、竹麻桑漆 |
| 风险 | 容易成为魏蜀争夺的前线 | 内部豪族、东州人士、南中和外来军队利益复杂 |
| 叙事意象 | 守门、迁徙、山路、前线仓储 | 富庶、封闭、资源争夺、旧臣新主整合 |

### 3.4 荆州与江东

- 荆州的价值在于中转：北面接中原，西面接益州，东面接江东，南面通交州。
- 江东的价值在于水网、稻作、船运和长江屏障，同时受地方大族与山越问题牵制。
- 长江既是防线也是道路；控制江面、渡口、船户和粮仓比“拥有一条大河”更重要。

## 四、人和：社会主体与资源关系

### 4.1 自耕农与小家庭

核心资源是土地、牛、农具、种子、劳动力和户籍资格。灾年时，家庭首先牺牲消费，随后借粮、卖地、依附豪强，最后进入奴婢、佃户或流民状态。

### 4.2 豪强、田庄与坞堡

豪强的力量不止是“土地多”，还包括：

- 免除或转移部分赋役的关系网络。
- 粮仓、盐仓、牲畜、农具和运输工具。
- 徒附、佃户、宾客和部曲。
- 与郡县官吏、士族和军队的联络。
- 在地方治安崩坏时提供保护的能力。

豪强“养民”既可能救命，也可能把流民变成依附人口；同一个粥棚可以同时具有慈善、招募和控制功能。

### 4.3 流民

流民不是一个固定阶层，而是一个过程身份：

> **原籍户 → 逃户 → 结伴流动 → 粥棚或宗教组织成员 → 佃户、部曲、军队或重新编户。**

不同阶段的流民需求不同：最初要水和粮，随后要安全，再之后要土地、身份和稳定的家庭生活。政权若只提供军役而不提供安置，流民可能转为新的叛乱力量。

### 4.4 士人、官吏与宗教组织

- 士人提供经学、文书、声望和政治判断。
- 官吏把皇帝的命令转换成户籍、征税、征发和司法。
- 太平道提供跨地域的信仰、治病叙事、组织和动员。
- 儒家灾异论提供了批评政权的语言，但未必能提供具体的粮食和组织。

### 4.5 军队与部曲

军队是消耗粮食的组织，也是国家收编人口、分配职位和获取土地的工具。部曲、降卒、郡国兵、募兵和流民兵的身份不同，忠诚对象也不同。

写一支军队时应回答：

1. 谁供粮？
2. 谁发饷或分赏？
3. 家属在哪里？
4. 战后会被安置、遣散还是继续征发？
5. 他们服从的是皇帝、州牧、将领、宗族还是自己的生存网络？

## 五、制度与技术：资源如何被组织

### 5.1 户籍与赋税

户籍是国家知道“谁在哪里、能交什么、能服什么役”的方式。战争、灾荒、豪族荫附和流民迁徙会使户籍失真；户籍越失真，国家越依赖临时征发，临时征发又进一步推动逃亡。

### 5.2 粮食与运输

一地富庶不等于军队马上能吃到粮食。粮食链包括：

> 生产 → 收获 → 储存 → 计量 → 征收或购买 → 车辆/舟船 → 道路/河流 → 仓门 → 军营或灾民。

任何一环被敌军、洪水、蝗灾、腐败、盗匪或官吏截断，都会造成“账上有粮，前线无粮”。

### 5.3 技术上限

- 农业：堆肥、区种、代田、灌溉、水碓等。
- 盐铁：井盐、火井、煮盐、高炉、炒钢、水排。
- 书写：蔡伦纸及东汉末纸，但简牍仍重要。
- 医疗：隔离、石灰、沸水、草药、焚烧病者衣物等朴素措施。

技术改变生产能力，但收益由谁控制同样重要；盐井和铁官可以让一地富起来，也可能让豪族、官府和军队争夺升级。

## 六、六条可重复使用的因果模板

### 模板一：灾荒转为流民

> 旱蝗/洪水 → 秋粮下降 → 旧粮提前耗尽 → 借贷和税役冲突 → 卖地或依附 → 逃亡 → 粥棚、宗教或军队收编。

### 模板二：疫病转为政治不信任

> 疫病传播 → 家庭和军营死亡 → 官府救治迟到 → 祷祠无效或医药不足 → 地方组织接管照料 → 朝廷合法性下降。

### 模板三：道路转为政权边界

> 山口/渡口/驿站被控制 → 粮食和文书可以通行 → 军队能够持续驻扎 → 郡县命令获得执行 → 地方势力成为区域政权。

### 模板四：豪强收民

> 灾民涌入 → 豪强提供粮食和保护 → 订立佃契或编入部曲 → 国家户籍减少 → 豪强更强 → 朝廷加征 → 更多人依附豪强。

### 模板五：战争转为国家化

> 将领获得兵 → 控制仓储和道路 → 收编流民/降卒 → 建立屯田与官署 → 发布诏令或使用宗室名义 → 临时军队变成政权。

### 模板六：地理转为三国格局

> 曹魏获得中原人口粮区；蜀汉获得益州山川与西部资源；孙吴获得长江水网与江东社会 → 三方互有防线但资源结构不同 → 长期竞争形成鼎立。

## 七、小说写作检查表

每个大事件至少写出以下五类细节：

- **天时**：当季的雨、旱、蝗、疫病、风向或青黄不接。
- **地利**：道路、河流、坡地、关隘、城门、仓储和视野。
- **人和**：谁在逃、谁在收、谁在征、谁在传话、谁从中获利。
- **制度**：文书、印信、户籍、赋税、军令、粮簿和官职。
- **后果**：普通人失去什么，又得到什么依附或选择。

> **核心判断**：历史中的“势”不是玄学，而是自然条件、资源运输、社会组织、制度能力和人的选择长期叠加后表现出来的方向性压力。
