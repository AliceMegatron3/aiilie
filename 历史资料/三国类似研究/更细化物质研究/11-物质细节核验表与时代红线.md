# 更细化物质研究 · 物质细节核验表与时代红线

> **用途**：正文、细纲和资料调用前的最后检查。这里不追求把所有细节判成绝对真伪，而是提醒“哪些可以直接写、哪些需要限定、哪些明显是后世倒灌”。

---

## 一、三档使用法

### A档：可直接作为汉末—三国背景

- 简牍、木牍、帛书；东汉纸张作为较贵或较新材料。
- 五铢钱、粮食、布帛、盐、牲畜和以物易物。
- 田租、算赋、口赋、更赋、户籍、里正、亭长、郡县文书。
- 麻、葛、丝、皮、毛、粗布、袍、襦、巾、帻、冠、草鞋、麻鞋、皮靴。
- 粟、黍、麦、稻、豆、蔬菜、鱼、猪、羊、鸡、酒、盐、酱、醋。
- 釜、甑、陶瓮、木碗、席、榻、案、几、灯盏、石磨、纺锤、算筹。
- 井盐、火井、煮盐、高炉生铁、炒钢、百炼钢、水排、水碓。
- 车、牛车、马车、驮具、渡船、粮船、栈道、驿站、关隘和烽火。
- 太平道、五斗米道传统、方士、巫祝、谶纬、官方祭祀和地方信仰。
- 旱蝗、疫病、青黄不接、病棚、隔离、石灰、沸水、艾草、草药。

### B档：可以写，但必须限定身份、地域、规模或来源

- 深衣、裤褶、特定冠制和军队服饰。
- 复杂织锦、提花、精细漆器和大型官营工坊。
- 大规模屯田、东州兵、州牧、地方宗教行政组织。
- 纸张在某些官署、士人和工坊中的使用。
- 义舍、祭酒、教民、符水、方术医疗和地方巫祝体系。
- 石灰改土、黑火药雏形、土法皂等本项目设定或上限技术。
- 城市门禁、夜禁、市场管理和驿传的具体执行方式。
- 乘马、军船、攻城器械和重型铠甲，需结合兵种和经济实力。
- 上巳、寒食、重阳等节令习俗的早期形态，需避免后世固定化。

### C档：禁止直接写，或只能作为后世传说/作者分析

- 乌纱帽、补服、品级纹样、明清官服和旗装。
- 现代内衣、拉链、松紧带、纽扣体系、成衣店和统一尺码。
- 银票、纸币、银行、身份证、现代路引、快递、供应链。
- 铁路、汽车、现代轮船、公路、水泥、玻璃窗、现代下水道。
- 成熟火药、火器、炸药、现代化学提纯、抗生素、疫苗和无菌手术。
- 唐宋以后成熟的茶馆文化、纸钱、门神、春联、成熟道观和宫观体系。
- “五虎上将”作为汉末正式官职、“军师”作为所有谋士通称、“蜀汉/东吴”作为当时人人统一自称。
- “菜人”“两脚羊”等明显后世词汇进入东汉正文。
- 把《三国演义》名场面直接当《三国志》正文：空城计、五关斩六将、草船借箭的诸葛亮版本、借东风法术等。

## 三、场景核验表

### 1. 时间

- [ ] 年号、月份、季节成立。
- [ ] 人物年龄和身份成立。
- [ ] 该技术、物件、官职或教派在此时已经存在。
- [ ] 灾害和疫病没有使用后来的专名。

### 2. 地点

- [ ] 城、县、郡、州名称符合当时行政沿革。
- [ ] 道路、河流、关隘和距离符合地域条件。
- [ ] 物产确实可能从当地获得或通过商路运来。
- [ ] 气候和作物与地点匹配。

### 3. 身份

- [ ] 人物的衣料、食物、住宅和器物符合财富与职业。
- [ ] 说话方式符合识字程度、关系和场合。
- [ ] 官员、士人、军人、工匠、流民和奴婢的权限没有混写。
- [ ] 女性、儿童、老人和伤病者拥有具体劳动与社会关系。

### 4. 物质

- [ ] 原料、工具、燃料、水和工匠存在。
- [ ] 物件有重量、磨损、维护、存放和运输问题。
- [ ] 粮食、钱、帛、盐、牲畜和土地的计量方式成立。
- [ ] 生产成果由谁占有、谁支付成本、谁承担风险清楚。

### 5. 思想宗教

- [ ] 人物引用的典故在时代、身份和教育程度上成立。
- [ ] 儒家、黄老、法家式行政、方术和民间教派没有被写成同一组织。
- [ ] 太平道信徒不自动等于叛军，五斗米道不自动等于成熟后世道教。
- [ ] 祭祀、经验医学和方术可以并存，不强行套用现代科学/迷信二分。

### 6. 阴谋与传闻

- [ ] 该说法是人物听到的、军报写的还是作者确认的？
- [ ] 是否存在来源、反证和利益动机？
- [ ] 后来发生的事情是否被倒灌成早期人物的预谋？
- [ ] 是否用一个秘密组织解释了本来可以由粮食、道路、官位和利益解释的事情？

## 五、五分钟快速检查

如果时间有限，只问十个问题：

1. 这件东西当时有吗？
2. 这个词当时有人这么说吗？
3. 这个人买得起或拿得到吗？
4. 原料和燃料从哪里来？
5. 谁做、谁运、谁保管？
6. 谁从中获利？
7. 当季天气会不会阻止这件事？
8. 这个地点是否有相应道路、水源和物产？
9. 角色知道的消息是否真的能传到？
10. 这段内容是正史、异说、传说、设定还是作者分析？

> **最终原则**：一个细节越具体，越需要来源和条件。写作不是把古代物件堆满，而是让每个物件都参与人物的生存、身份、关系和选择。
