# 更细化物质研究 · 衣冠服饰与身体装束

> **使用原则**：服饰同时体现材料、气候、劳动、身份和礼仪。不要只把衣服当颜色描写；一件衣服的纤维、缝法、破损、洁净和佩饰都能透露人物处境。
>
> **时代边界**：东汉末与三国服饰有连续性，也有军队、宫廷、地域和阶层差异。画像石、墓葬和文献可互证，但不能把某一幅贵族画像当作全民日常。

---

## 一、衣料来源

| 材料 | 来源/特点 | 常见使用者与场景 |
|---|---|---|
| 麻、苎麻 | 适合普通衣物、绳索、布料，耐用但手感粗 | 农户、工匠、劳作、夏季 |
| 葛 | 可织布，常用于平民和夏衣 | 普通家庭、劳作、行旅 |
| 丝、帛 | 轻柔、体面、可作货币和礼物，成本高 | 士族、官吏、富户、礼服和赠礼 |
| 皮革 | 鞋、带、护具、冬衣或军用 | 军人、猎户、北方和寒地人口 |
| 毛、毡 | 保暖、毡帐和边地生活 | 凉州、并州、幽州、牧民、军队 |
| 褐/粗布 | 粗厚布衣的身份和生活意象 | 贫民、隐者、役夫、劳作 |
| 织锦、绣品 | 成都等地的高价值织物 | 豪门、礼物、官府赏赐、富贵人物 |

“布衣”可以指平民身份，也可以是实际麻葛衣物；“锦衣”不是所有富户每天穿的常服，要看场合和财富。

## 二、上衣、下衣与常见装束

### 2.1 袍与深衣

- 袍可作长衣，内有里衬和絮料，材料与厚薄差异大。
- 深衣具有礼仪和身份意味，不能把所有长衣都称作深衣。
- 官员、士人和富户在正式场合更重视衣冠完整。
- 劳动者穿长衣会妨碍下田、爬栈道和炉边做工，通常需要束衣、短衣或便于行动的装束。

### 2.2 襦、短衣与裙裤

- 襦可作短上衣，男女和地域使用不同。
- 下身可有裙、裳、裤等装束，具体形态随身份和劳动场景变化。
- 骑马、行军、山路和劳作更需要便于分腿、束紧和保护腿部的衣物。
- “裤褶”等军旅、骑射相关装束要结合画像、时代和身份使用，不能泛化成所有士兵的统一制服。

### 2.3 普通人的衣服状态

- 一件衣服可能反复改短、补洞、拼接、翻面和给孩子穿。
- 衣领、袖口、膝部和下摆最容易脏破。
- 贫困人物不一定“衣不蔽体”，也可能只有一件勉强完整的冬衣，睡觉时兼作被子。
- 灾民衣物会混有麻絮、草屑、血迹、烟味和药草味。

## 三、冠、巾、帻与发式

### 3.1 发式和束发

成年男子通常重视束发、冠巾和发髻；劳动、军旅、服丧、囚徒和奴婢状态可能改变头发装束。女子发髻、簪、笄和束发也有年龄、婚姻和阶层差异。

### 3.2 冠

冠有礼仪和身份功能，不是日常所有人都戴。士人、官吏和贵族在正式场合需重视冠服；农人下田、工匠入炉和流民赶路不可能始终冠带整齐。

### 3.3 巾

巾可用于束发、包头、擦汗、御尘和身份表达。黄巾起义的“黄巾”具有政治标志意味，不能把它写成普通百姓平日都戴的统一帽子。

### 3.4 帻

帻与汉代男子头部装束、官服和身份有关；具体样式有时代和阶层差异。不要把后世影视剧中的黑色帽子一概称为乌纱帽，乌纱帽属于后世成熟形象。

## 四、鞋、袜、带和佩饰

| 物件 | 可写功能 | 细节 |
|---|---|---|
| 草鞋 | 贫民、流民、农人、山路 | 草梗刺脚、易湿、需反复编补 |
| 麻鞋/布鞋 | 日常步行和劳作 | 鞋底磨薄、沾泥、湿后变硬 |
| 木屐 | 特定地区、雨湿环境或室内外转换 | 走路声、湿地、泥泞，不能当全民鞋 |
| 皮靴 | 骑兵、寒地、军队和牧民 | 防寒、防湿、便于骑马 |
| 腰带 | 束衣、挂物、身份和实用 | 可挂刀、囊、钥、算筹或小物 |
| 布囊/褡裢 | 装粮、钱、药、文书 | 流民、商人和行旅者的随身财物 |
| 簪、笄、玉佩 | 发饰、礼仪、身份和家产 | 玉佩不能随意给普通农妇和士卒使用 |
| 印绶、佩刀 | 官职、军职和权限 | 不能把现代勋章式佩饰前置 |

服饰描写应包括“穿起来怎样走路”：山路人物鞋底打滑，工匠袖口束紧，军人腰带不能妨碍拔刀，妇女抱孩子时衣袖和裙裳如何处理。

## 五、按身份和场合调用

### 1. 自耕农

麻葛短衣、补丁、束腰、草鞋，雨天披蓑或裹旧布；下田时不讲究完整礼仪，衣物重耐磨和易洗。

### 2. 流民

衣物来源混杂：旧农衣、主家发衣、军中旧衣、抢来的布片、亲人遗物。颜色褪杂、尺寸不合、补丁叠补，比统一“破衣烂衫”更真实。

### 3. 佃户与部曲

可能比流民有更稳定的粗布衣，也可能穿主家发放的旧衣；部曲在守墙、出战和日常劳动时会有不同装束。

### 4. 士人和官吏

衣冠、佩绶、鞋履、袖口和衣料体现身份；赴宴、上朝、出行、守丧和避乱时不同。清贫士人也可能衣服旧但仍努力保持冠带和礼节。

### 5. 商人

衣物重耐行、耐脏和便于藏钱；富商可用丝帛、佩玉、皮带显示资本，但不能只靠衣服判断财富。

### 6. 军人

衣甲、胫衣、鞋、头巾、护腕和腰带需配合兵器。普通军人装备常有补修和混杂，不要让每支军队都穿完全统一的新铠甲。

### 7. 妇女

衣物受劳动、婚姻、财富和地域影响。纺织妇女手上有茧，袖口可能夹灰；富户妇女在正式场合需要更多层衣、发饰和佩物，但逃难时也会迅速减负。

## 六、颜色与身份使用边界

- 赤、朱、玄、白等颜色在礼制、祭祀、军旗和贵族服饰中有象征意义，但不要把颜色系统写成现代制服编码。
- 黄巾作为起义标志要放在184年之后；此前可写民间头巾，但不能让人物知道“黄巾军”这一政治称谓。
- 白衣、麻衣、素服可能与服丧、贫困、隐逸或实际材料相关，必须结合场合。
- “紫色高贵”“蓝色平民”等现代色彩标签不能直接套用。

---

## 七、身体经验与服饰

服装会制造身体感：

- 麻布磨脖颈，汗湿后发硬。
- 冬衣絮料受潮，贴在身上沉重。
- 破鞋进砂，脚底磨出血泡。
- 腰带勒紧会压住空腹和伤口。
- 冠巾在风雨和奔跑中容易松脱。
- 铠甲闷热、沉重，长途行军需要脱卸和晾晒。

写人物时，衣物可以成为社会变化的计量器：衣服从有里到无里，从合身到借来的，从佩玉到只剩布绳，读者就能看见阶层滑落。

---

## 八、服饰时代红线

- 乌纱帽、补服、官服胸前品级纹样、马褂、旗装等后世形制不能提前。
- 不能把“汉服”当作汉末人自己的统一现代标签；正文写具体衣物和场合。
- 现代内衣、拉链、松紧带、纽扣体系、成衣店和统一尺码不能提前。
- 铠甲形制要按汉末画像、出土资料和军种谨慎选择，不要把明清铠甲或影视鳞甲套用。
- 棉布在东汉末不是普通民众普遍衣料，麻、葛、丝、皮、毛和粗布更稳妥；棉花相关内容需谨慎。

> **核心结论**：衣服既是材料，也是身份、劳动、气候、贫富和礼仪的可视化记录。写服饰最有效的方式不是罗列款式，而是写它如何贴在人的身体上、如何限制人的行动、如何随着生活变坏或变好。
