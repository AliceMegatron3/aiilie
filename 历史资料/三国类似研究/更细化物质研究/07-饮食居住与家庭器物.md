# 更细化物质研究 · 饮食、居住与家庭器物

> **核心问题**：汉末人物每天吃什么、在哪里睡、如何烧火、如何储粮、怎样照料孩子和病人？物质生活要按地域、阶层、季节和战争状态区分。

---

## 一、主食与粮食层级

### 1. 粟与黍

北方和黄河流域常见粟、黍等杂粮。粟可以煮饭、熬粥、酿酒，也可作为军粮和交易物。粮食是否脱壳、是否发霉、是否掺杂，会直接影响口感和饱腹感。

### 2. 麦

麦可磨粉或煮食，收获和加工需要具体工具。普通家庭未必随时吃白面，石磨、筛分、燃料和时间都会影响成品。

### 3. 稻

长江流域、荆州、江东和部分南方地区稻作更重要；不同地域的粮食结构不能被北方粟米一概替代。

### 4. 豆、麻籽和杂粮

豆类可补充蛋白，也可作粥、羹和饲料；麻籽、黍稷、菽等作物随地域和季节变化。写饥荒时可写粮食降级：精粮变粗粮，粗粮掺糠，最后吃野菜、树皮和草根。

---

## 二、肉、蔬菜、果品与调味

| 类别 | 可写内容 | 阶层/场景 |
|---|---|---|
| 肉类 | 猪、羊、鸡、鸭、狗、鱼、兔、猎物 | 豪门宴饮、军营、节令、祭祀；普通人并非天天吃肉 |
| 鱼虾 | 河流、湖泊、长江水网、池塘 | 渔户、船户、江东、巴蜀和荆州 |
| 蔬菜 | 葵、韭、葱、芥、瓜、菘类和野菜 | 家庭菜圃、田边、灾年采集 |
| 果品 | 枣、栗、梨、桃、梅、桑椹等 | 季节性食物、干果和礼物 |
| 调味 | 盐、酱、醋、姜、葱、椒等 | 盐的价格和获取渠道会影响普通家庭 |
| 油脂 | 动物油、麻油等 | 烹饪、灯火、药物和工艺，数量有限 |
| 奶类 | 北方和牧区更常见 | 不能把奶制品当汉地全民主食 |

### 食物写法

- 粥：稀厚、掺糠、能否看见米粒、是否有油花。
- 饭：蒸、煮、蒸熟后颗粒状态；不同粮食口感不同。
- 羹：粮、菜、肉或豆煮成的浓汤，适合写家庭和军营。
- 饼：需要磨粉、和面、火候和锅具；不要把现代面包店结构提前。
- 腌藏：盐、酱、醋、风干、烟熏和陶瓮都需要成本。

## 三、饮料与宴饮

- 水是最基本的饮品，但井水、河水、雨水和泉水的清洁度不同。
- 酒可由粮食酿制，既用于宴饮、祭祀、馈赠、军功和医疗，也会与粮食短缺发生冲突。
- 茶作为后世普遍饮品不能简单前置；可写药饮、汤饮、热水、米浆、果浆和酒。
- 富户宴饮重在器物、座次、肉食、酒、乐舞和宾客关系，不只是“吃得豪华”。
- 军营宴饮要考虑军粮、奖赏和将领与士卒的距离。

---

## 四、灶、火与烹饪器具

### 4.1 灶

普通家庭可有地灶、灶台、烟道或简易火塘；坞堡、军营和豪门厨房规模更大。灶的位置影响取水、排烟、柴草和防火。

### 4.2 常见器物

- 釜、锅：煮饭、熬粥、煮肉和烧水。
- 甑：蒸煮粮食，需要配合釜和水汽。
- 盆、碗、盂：陶、木、漆、铜等材质体现财富。
- 瓮、罐、缶：储粮、储水、腌菜、酿酒和装油。
- 匕、箸、勺：进食方式随时代、地域、食物和阶层变化。
- 砧板、刀、石磨、筛：粮食加工和厨房劳动。

普通家庭的器物常一物多用：破陶罐可接水、装种子、盛灰或当夜壶；贵重铜器不会随便放在流民锅里。

## 五、住宅类型

### 5.1 农户住宅

可能有土墙、木架、草顶、瓦顶、院落、灶间、牲畜栏和储藏处。住房受当地土质、雨水、木料、气候和财富影响，不能把所有房子都写成砖瓦院落。

### 5.2 豪强庄园和坞堡

- 高墙、门楼、壕沟、粮仓、盐仓、牲畜圈和部曲住所。
- 居住区与生产区相连，既是庄园也是防御点。
- 流民被安置在边缘、工坊、佃户区或临时棚屋。
- 门房、管事、仓吏和护卫掌握不同权限。

### 5.3 城市宅院

官吏、商人和士族住宅可能靠近市、官署、里门、渡口或交通线。城市中的门禁、邻里、夜禁和火灾风险比乡村更明显。

### 5.4 驿站、客舍与寺观性质场所

驿站承担官方交通，客舍和商旅店并非现代旅馆；费用、身份、马匹、食物和安全取决于地方情况。寺观、祭坛和宗教场所应按具体年代和地点写，不要把后世成熟寺院格局提前。

---

## 六、室内空间与睡眠

- 床、榻、席、褥、被、枕等器物因阶层和财富不同而不同。
- 普通人可能席地而卧，床榻也可用于坐卧和会客。
- 富户厅堂有坐席、屏风、案几、灯火和分隔空间。
- 家庭空间往往混合储粮、纺织、育儿、炊煮和睡眠，隐私程度与现代住宅不同。
- 冬季保暖靠衣被、火塘、墙体、炕式结构或多人同室，具体形制按地域核验。

### 睡眠细节

- 夜里先确认门闩、柴火、粮袋和孩子。
- 流民以草席、车旁、屋檐、庙社边、废屋和树下过夜。
- 军营睡眠取决于轮值、鼓更、兵器和马匹，士卒不能整夜安睡。
- 富户睡处与仆役、护卫、库房的距离可以制造悬疑和权力感。

---

## 七、储藏、清洁与家庭卫生

### 储藏

- 粮食放在仓、囷、瓮、囊、木箱或高处，防潮、防鼠、防盗。
- 种子要与食粮区分，藏于干燥、相对隐蔽的位置。
- 盐、油、药材、布匹、铁器和钱帛需要不同的防潮与看守方式。
- 账簿和封泥能证明仓储是否被打开、替换或偷取。

### 清洁

- 汲水、洗手、洗脚、换衣和清理灶台取决于水源和燃料。
- 艾草、草木灰、热水、石灰和日晒可作为朴素的清洁或防疫措施。
- 没有现代厕所和下水道，粪便、污水和尸体处理影响疾病与气味。
- 富户与军营可能有更明确的排泄区，流民和战场环境则更混乱。

### 家庭卫生与礼仪

清洁既是实际需求，也是礼仪和身份表现。士人进堂前整衣、洗手或整理冠带；普通人没有精细洁癖体系，但会认识到发臭、腐败、虫害和病人的危险。

## 八、家庭器物与人物身份

| 器物 | 透露的信息 |
|---|---|
| 陶瓮 | 家庭储藏量、是否有余粮、是否会腌藏酿酒 |
| 铜釜 | 财富、军需、豪门厨房或祭祀场合 |
| 木碗 | 普通家庭和行旅耐用器物 |
| 漆器 | 富户、礼物、地方工艺和身份体面 |
| 算筹 | 商人、管事、吏员、工坊和粮簿 |
| 砚、刀笔、简牍 | 识字、官文书、私信和教育 |
| 灯盏 | 夜间工作能力、油脂和财富 |
| 镰、锄、耒耜 | 生产身份、田地和劳动状况 |
| 针线、纺锤 | 家庭纺织和女性劳动 |
| 锁、木牌、印章 | 奴婢、仓库、户籍、文书和权限 |
| 褡裢、背篓 | 流民、商旅、采集和行军后勤 |

## 九、不同地区的饮食居住差异

### 关中、三辅、凉州

粟麦、牲畜、羊肉、粗粮、旱地和军粮运输更重要；寒冷、风沙、缺水和长期战乱会影响住宅、衣物和储藏。

### 益州、巴蜀

稻作、粟麦、鱼、盐、竹、桑、漆和水利资源更丰富；山地道路、湿热、虫害和河流洪水需要不同的房屋和储藏方法。

### 荆州、江东

稻、鱼、菱藕、舟船、水网和湿气明显；住宅、交通、饮食和军队都更依赖水路。

### 南中

山地、多种作物、地方物产和族群习俗差异大；不能用成都平原农户的衣食住行覆盖南中。

## 十、饮食居住时代红线

- 茶馆、咖啡、白糖甜点、炒菜体系、现代面条店不能直接提前。
- 玻璃窗、纸窗普及、现代门锁、砖混楼房和水泥路不能提前。
- “一日三餐”不能机械套用所有阶层和季节；普通人进食次数取决于粮食和劳动。
- “桌椅板凳”不能作为全社会统一家具；席、榻、案、几和床的使用要分场合。
- 纸钱、门神、春联、成熟道观和后世民俗体系需按来源和年代核验。
- 食物不能只按现代菜名出现，要写原料、加工方式、锅具、燃料和储藏。

> **核心结论**：最有力量的生活细节往往不是珍馐美味，而是一个家庭有几只完整的陶罐、今晚能烧几把柴、种子藏在哪里、谁睡在门边、谁知道仓门的封泥有没有被动过。
