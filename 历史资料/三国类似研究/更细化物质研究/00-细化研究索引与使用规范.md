# 三国类似研究 · 更细化物质研究

> **定位**：本目录补足东汉末年至三国时期的日常物质、社会利益、思想宗教、语言文字和技术现场，服务于小说中的“人如何生活、如何说话、如何做工、如何交换、如何相信”。
>
> **时间重点**：东汉中晚期至三国（约168—280年）。凡技术、称谓或习俗有明显时代变化，必须按年份调用。
>
> **资料原则**：正史和制度文献提供骨架，考古和出土简牍补足器物与生活，后世笔记与网络文章只能作为线索。本文档中的“可写”不等于“每个地区都普遍存在”。

## 二、调用顺序

1. 先用上级目录 `01-东汉历史主线·时间事件地点天时地利.md` 确定年代和地点。
2. 再用 `01-利益结构与社会身份.md` 判断人物凭什么活、凭什么交换、凭什么服从。
3. 需要思想或宗教时，分别打开 `03` 和 `04`，不要把儒家、道家、法家、方术、民间信仰混成一个体系。
4. 写人物开口、写文书和书信时打开 `05`；写衣食住行和器物时打开 `06—10`。
5. 最后用 `11` 做时间红线检查，尤其防止把唐宋明清的词、物件和制度提前。

## 三、证据标记

- **【正史】**：《三国志》《后汉书》等正文明确记载。
- **【制度】**：官制、礼制、律令、赋税和文书材料支持。
- **【考古】**：墓葬、画像石、简牍、器物和遗址提供旁证。
- **【传世文献】**：先秦至汉代典籍、赋、论、医书、农书等。
- **【后世参照】**：后代文献可以帮助理解，但不能直接证明汉末普遍如此。
- **【设定】**：为小说服务的合理化安排，必须在正文或作者笔记中保留距离。
- **【禁写】**：时代明确不成立，或容易造成严重误读。

## 四、我判断还需要补足的主题

除用户点名的利益、民俗、诸子、教派、衣服、手工和语言外，本目录增加了五组必要内容：

1. **医疗卫生**：疫病、饮水、厕所、尸体和清洁会直接改变流民与军队场景。
2. **时间历法**：古人按年号、节气、月令、漏刻和更鼓生活，不能只用现代日期推进。
3. **城市交通与市场**：一件物品能否出现，取决于它能否被生产、运输、售卖和计价。
4. **家庭与性别劳动**：衣食、纺织、酿造、育儿、婚姻和继承都由家庭分工支撑。
5. **核验与红线**：物质细节最容易从影视、游戏和后世小说倒灌，必须单独设检查表。

## 六、总原则

- 不把“汉人”写成单一生活方式：洛阳士人、凉州军户、益州农户、江东船户、南中首领的物质生活不同。
- 不把“民俗”写成整齐统一的全国风俗：城乡、阶层、地域和宗教身份会改变习惯。
- 不把“思想”写成现代学派标签：汉末人物未必自称“法家”“道家”，他们更可能引用经书、方术、黄老或具体权术语言。
- 不把“技术”写成发明清单：技术必须落到材料、工具、工匠、燃料、时间、成本和收益分配。
- 不把“语言”写成古装剧台词：书面文和口头话不同，身份、场合、关系会改变说法。
- 不把网络说法写成史实：任何“秘史”“揭秘”“其实都是”都要回到来源、时间和证据。

> **总调用公式**：人物身份 + 具体地点 + 当季天时 + 手边材料 + 所属利益关系 + 当时能说的话 = 可信的三国场景。
