# 更细化物质研究 · 儒家、道家、法家典故与政治观念

> **先做区分**：汉末人物不会像现代课堂那样整齐地自称“我是儒家”“我是法家”。他们可能同时读经、谈黄老、用法术、信灾异、敬祖祭祀，并在实际治理中采取强制征发。
>
> **本文用途**：整理可用于人物台词、政论、诏书、士人争论和政治行动的思想资源，不把后世哲学分类机械倒灌到东汉末年。

---

## 一、汉末思想环境的基本样貌

### 1. 多套语言并存

- **经学和儒家礼制**：解释君臣、父子、名分、孝廉、祭祀、教育和政治责任。
- **黄老和道家资源**：谈清静、少扰民、节制欲望、顺势、养生、无为而治；也可与帝国行政结合。
- **法家式行政技术**：重名实、赏罚、军令、户籍、征发、考核和强制执行；不一定以“法家”名义出现。
- **谶纬与灾异**：用天象、符命、预言和祥瑞解释政权正当性与危机。
- **民间方术和宗教**：治病、求雨、驱邪、禳灾、发愿、结社、互助和传道。
- **名士清议**：用人物品评、道德声望和政治批评形成士人网络。

汉末危机不是“儒家失效后道家接管”，而是多套语言同时竞争解释现实。

## 二、儒家：礼制、责任与士人政治

### 2.1 儒家在现实中的内容

小说中可以把儒家写成具体行动，而不是只写背书：

- 服丧、祭祖、敬长、婚姻和继承。
- 读经、入太学、举孝廉、征辟和清议。
- 上书论灾异，认为君主应修德、节欲、恤民。
- 以“名分”判断废立、篡夺、叛乱和归附。
- 以乡里声望、门生故吏和人物评价形成政治资本。

### 2.2 可调用典故与观念

| 典故/观念 | 常见出处或背景 | 可写含义 |
|---|---|---|
| 克己复礼 | 《论语》 | 士人批评宫廷奢侈、要求恢复秩序 |
| 民为贵、社稷次之、君为轻 | 《孟子》 | 讨论灾荒、暴政与君主责任；须注意不是汉末人人日常引用原句 |
| 得道多助，失道寡助 | 《孟子》 | 诸侯争夺民心的士人论辩 |
| 君君、臣臣、父父、子子 | 《论语》 | 讨论废立、臣下越权和家族秩序 |
| 孝与忠 | 先秦儒家及汉代政治教化 | 解释举孝廉、服丧、忠于君父的冲突 |
| 天人感应 | 董仲舒以来的政治解释 | 把地震、蝗灾、疫病与君主失德相连 |
| 名正言顺 | 名分政治的通俗化表达 | 说明檄文、诏令和宗室名义的重要性 |
| 先天下之忧等后世熟语 | 北宋以后成熟 | **不能提前直用**，可改写为汉末士人忧国、恤民的语气 |

“典故可用”不等于人物会完整背诵后世名句。更真实的写法是让人物使用其中的思路，或由经师、太学生、官吏引用符合时代的经典语句。

### 2.3 儒家内部的冲突

- 经学章句与现实行政之间的冲突。
- 清议批评宦官，但清议未必能赈灾。
- 士人要求恤民，却可能维护门第、土地和礼法秩序。
- 忠于汉室与选择新主之间的冲突。
- 孝服、家族责任与赴任、从军、逃难之间的冲突。

## 三、道家与黄老：清静、养生和顺势

### 3.1 道家资源的几个层面

“道家”至少有三种使用方式：

1. **哲学文本**：老子、庄子中的道、无为、自然、柔弱、齐物等思想。
2. **黄老政治**：汉代以来以清静、少扰民、刑名与行政相结合的治理资源。
3. **民间方术和宗教道教的前身**：求仙、炼养、符箓、治病、禳灾和传道。

东汉末的太平道、五斗米道不能简单等同于成熟的后世道教；但它们吸收了方术、鬼神、老子崇奉、治病和组织实践。

### 3.2 可用典故与观念

| 观念 | 适用人物 | 场景用法 |
|---|---|---|
| 无为而治 | 隐士、地方治理者、厌恶乱政者 | 争论是否少征发、少扰民 |
| 反者道之动 | 谋士或方士的局势判断 | 以盛衰循环解释政权和军势 |
| 柔弱胜刚强 | 老者、谋士、受压者 | 讨论避战、守势、以退为进 |
| 上善若水 | 士人、隐者、治水者 | 适合水利和人格比喻，但不要过量使用后世鸡汤式表达 |
| 天地不仁 | 经历灾荒者或悲观人物 | 讨论灾害无差别，不等于现代无神论 |
| 清静少扰 | 黄老式官吏 | 反对重税、苛法和频繁征发 |

### 3.3 无为不等于什么都不做

汉末人物说“无为”，可能是在：

- 反对宫室工程和无休止征发。
- 要求官府少扰民、让农民恢复生产。
- 以静观局势、减少公开承诺。
- 作为隐士或士人对乱世的自我保护。

它不必然意味着没有行政技术，也不等于现代“躺平”。黄老式治理可以同时重视户籍、仓储和赏罚，只是强调少扰和顺势。

## 四、法家式治理：术语可以后置，行政实践不能缺席

### 4.1 为什么不能简单写“某人是法家”

汉代政治长期以儒家名分包装国家制度，同时使用大量法家式行政技术。人物很少需要宣称“我信法家”，他们会直接：

- 定户籍、编里伍。
- 核算田亩、征收钱粮。
- 设赏罚、军法和连坐。
- 以文书、印信和考核控制属吏。
- 用严刑震慑盗匪、叛乱和逃亡。
- 迁民、编屯、收编降卒。

这些做法可以被现代研究称为“法家式”或“刑名技术”，正文宜写行动和具体制度。

### 4.2 可调用典故和观念

| 观念 | 传统来源 | 三国场景用途 |
|---|---|---|
| 法不阿贵 | 《韩非子》等法家传统 | 官吏宣称不因豪强身份免罪；实际执行可被利益扭曲 |
| 刑过不避大臣，赏善不遗匹夫 | 法家政治格言传统 | 军法、赏功、惩逃兵的争论 |
| 名实相副 | 韩非子及刑名传统 | 核对官职、军功、粮簿和户籍是否相符 |
| 信赏必罚 | 法家和军政共同语言 | 将领建立军令信用 |
| 以法治国 | 后世概括 | 可作作者分析，汉末人物更可能说法令、刑名、赏罚 |
| 什伍连坐 | 秦汉基层控制传统 | 里社、军营、逃户和治安场景；注意具体执行年代与地区 |

### 4.3 法与情的冲突

- 疫病中是否允许逃户进城。
- 盗粮者是按盗窃处置，还是因饥荒减刑。
- 豪强部曲犯法，县令敢不敢捕。
- 降卒是按敌军处置，还是按新户安置。
- 私盐、私铁、逃役和卖身契如何处理。

法家式行政最有戏的地方，不是冷冰冰的口号，而是执行者在法、上命、乡情和自身安全之间做选择。

## 五、儒、道、法三种资源的交叉使用

| 场景 | 儒家语言 | 道家/黄老语言 | 法家式语言 |
|---|---|---|---|
| 灾荒 | 恤民、修德、天谴 | 少扰、清静、养民 | 仓储、登记、配额、禁聚 |
| 叛乱 | 名分、忠逆、正统 | 乱极则变、顺势 | 军法、赏罚、编伍 |
| 赈济 | 仁政、父母官 | 少征发、使民自生 | 粮簿、户籍、限额 |
| 任官 | 孝廉、德行、清议 | 隐逸、知止、顺时 | 名实、考核、功劳 |
| 战争 | 君臣大义、复汉 | 以弱胜强、避实击虚 | 军令、粮道、军功 |
| 地方治理 | 教化、乡约、礼法 | 因地制宜、少扰民 | 关卡、刑罚、征发 |

人物可以在同一场争论中切换三套语言，这比让每个人固定对应一个学派更接近汉末思想。

## 六、典故使用红线

- 《三国演义》中的后世台词不能自动作为汉末通行语。
- “以人为本”“人民至上”“生产力”等现代理论词只能出现在作者分析，不能进人物古代口语。
- “先天下之忧而忧”“天下兴亡，匹夫有责”等宋明以后名句不可提前。
- “法家”“道家”“儒家”可在现代研究中使用，正文人物宜说经、黄老、刑名、礼、清议、方术等更具体的词。
- 《道德经》《论语》《孟子》《韩非子》的引文要核对时代传播、版本和人物身份；农民、士卒和工匠不会都能背诵整章。

## 七、人物台词样式

### 太学生

> “蝗落三辅，宫中却还在采木。天子若不自省，明年谁替他收这片田？”

### 黄老式隐士

> “少发一趟役，田里便多一双手。官府若日日来扰，便是把活人赶成了盗。”

### 县吏

> “名册上少一户，仓里便少一份；你说他是逃民，我只问印在哪里、粮从何处补。”

### 军法吏

> “军令不是给勇者看的，是给每一个想退的人看的。”

### 方士或教徒

> “病不是你一家招来的，救也不该只救你一家。先把病人移到下风处，再说符水灵不灵。”

> 以上为风格示例，不是史料原句；正文使用时应按人物身份和时代语汇改写。
