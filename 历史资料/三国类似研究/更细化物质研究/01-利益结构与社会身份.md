# 更细化物质研究 · 利益结构与社会身份

> **核心问题**：一个三国时代的人凭什么活着，向谁交粮、服役和求保护，为什么加入某个主家、军队、宗教或政权？
>
> **使用边界**：东汉末年没有现代“阶级”“职业身份”一一对应的固定标签。下表是分析工具，正文要用当时的身份、官职、户籍和关系表达。

---

## 一、身份不是一张标签，而是五层关系

一个人可能同时拥有：

1. **户籍身份**：编户、逃户、流民、属国民、降户、屯田民等。
2. **法律身份**：良民、奴婢、罪徒、俘虏、部曲或依附人口。
3. **生产身份**：自耕农、佃户、徒附、盐户、铁工、织工、车夫、船户、商人。
4. **政治身份**：官吏、士人、宗室、州牧属吏、军人、部曲将、门生故吏。
5. **私人关系身份**：某家宾客、某将亲兵、某豪强佃户、某宗教首领的徒众、某族长的亲属。

写人物时至少给出其中两层，人物才不会像脱离社会的“现代个人”。

## 二、利益主体速查

| 主体 | 主要收入/资源 | 主要风险 | 典型选择 |
|---|---|---|---|
| 皇帝与宫廷 | 田租、算赋、贡赋、卖官、地方输送 | 宫廷财政不足、军队不受控、权臣挟持 | 依宦官、赦免、加派、改任州牧、重组禁军 |
| 宦官集团 | 宫廷信息、任官、赏赐、地产和政治中介 | 失去皇帝信任、外戚清洗、士人攻讦 | 控制诏令、结党、收受财货、扶植代理人 |
| 外戚 | 皇后亲族、禁军、宫廷职位、姻亲网络 | 宦官反扑、皇帝成年、士人不支持 | 联合士人、调兵入京、争夺辅政权 |
| 士人/士族 | 经学声望、官职、门生故吏、土地和婚姻 | 党锢、政权更替、家族被诛 | 上书、清议、择主、避乱、结交军政集团 |
| 地方官 | 征收、司法、任官和文书权 | 上级考核、军乱、豪强反抗 | 催科、结豪强、募兵、报功或隐瞒灾情 |
| 豪强地主 | 土地、粮仓、佃户、部曲、盐铁和借贷 | 军队掠夺、官府征发、族内分产 | 收民、筑坞堡、养部曲、交结州郡、投资盐铁 |
| 自耕农 | 土地、家庭劳力、牛、种子和户籍 | 旱蝗、疫病、税役、借贷、征兵 | 节食、借粮、卖地、依附、逃亡、入军 |
| 佃户/徒附 | 主家土地、仓粮和保护 | 租率、私役、主家惩罚、战争 | 留庄、逃亡、转投另一豪强、加入军队 |
| 奴婢 | 主家供养、劳动、家庭关系 | 买卖、处分、分离、放逐 | 服役、逃亡、求赎、依附其他人 |
| 商人 | 谷、盐、铁、帛、马匹和运输差价 | 倍算、劫掠、关卡、战乱和价格波动 | 换货、囤积、结交官府、雇护卫、改走水路 |
| 工匠 | 技术、工坊、原料、订单和主家供养 | 征发、技术被夺、原料断供 | 依附官府、豪强或军队，传承手艺 |
| 军人/部曲 | 口粮、赏赐、官位、战利品和主将保护 | 断粮、战败、军法、家属失散 | 跟随主将、投降、抢掠、屯田、归附新主 |
| 宗教徒众 | 组织救济、互助、身份和信仰 | 官府镇压、内部纪律、战争 | 传道、治病、结社、避乱、起事或归附 |
| 妇女与儿童 | 家庭劳力、纺织、婚姻和继承关系 | 战乱、卖身、婚姻交易、失去家属 | 织作、照料、逃亡、再婚、依附主家或宗族 |

## 三、家庭如何分配风险

### 3.1 小农家庭

- 男性劳力通常承担耕作、服役、远行和军役风险。
- 女性承担纺织、缝补、育儿、炊事、家禽和部分田间劳动。
- 老人掌握粮食记忆、婚姻关系、祖坟和乡里信用。
- 儿童既是口粮消耗者，也是未来劳力、口赋对象和婚姻资源。

“卖身”不只意味着个人失去自由，也可能是家庭用一个成员换取其他人暂时活下去的策略。小说要写决定者的痛苦，也要写粮食账本背后的现实约束。

### 3.2 豪强家庭

豪强家族的内部利益并不一致：嫡庶、兄弟、姻亲、分产、官职和军权都可能发生冲突。一个年轻继承人可能要在：

- 保住祖产。
- 拒绝或接受州郡征发。
- 保护佃户以维持生产。
- 交出部曲以换取官职。
- 选择支持旧主还是新主。

之间做选择。豪强不是一个永远一致的“反派阶层”。

### 3.3 军人家庭

军队成员的家属在哪里，决定军队是否稳定。军人若家属随军，会增加粮食压力；家属留在原籍，则军人更依赖主将和军饷。降卒、流民兵和部曲尤其需要通过分配土地、编户或家属安置来建立新忠诚。

## 四、利益冲突的六种常见形式

### 1. 税粮冲突

官府要足额，农户无余粮；乡吏可能以低斗、高秤、附加杂役弥补上级压力；豪强则通过荫庇人口和报功关系减少负担。

### 2. 土地冲突

灾年地价下跌，豪强收地；农民知道卖地等于失去未来，却必须先偿还借粮、税赋和丧葬债。

### 3. 人口冲突

国家要户籍和兵役，豪强要佃户和部曲，宗教组织要徒众，军队要兵源；同一个流民可能同时被四方争夺。

### 4. 道路冲突

关隘、渡口、驿站和桥梁决定粮食和文书能否通行。守关者收取“过路钱”、商人要求通行、军队要求优先，最容易形成地方权力。

### 5. 技术冲突

盐井、火井、铁官、造纸和水利能提高收益，利益冲突会围绕井权、工匠、燃料、税率和销售路线展开。

### 6. 名分冲突

“奉汉”“宗室”“讨贼”“救民”“复仇”“清君侧”都是把资源竞争说成正当政治行动的语言。口号不一定是假的，但口号背后必有具体的粮、地、官位或安全问题。

## 五、身份转换路径

### 小农

> 自耕农 → 借贷户 → 佃户/徒附 → 流民 → 宗教徒众/军人/部曲 → 重新编户或继续迁徙。

### 士人

> 太学或乡里声望 → 举孝廉/征辟 → 郡县官 → 党锢或避乱 → 择主 → 新政权官僚。

### 边疆人口

> 部落成员 → 互市者/质子 → 归附者/属国民 → 郡兵或部曲 → 地方首领/官号持有者。

### 工匠

> 家传手艺 → 主家工坊 → 官府工官 → 军工或盐铁作坊 → 迁徙、隐匿或被新主接收。

这些路径可以交叉，一个人可能在不同阶段拥有不同身份。

## 六、小说核验问题

1. 这个人物的粮从哪里来？
2. 他是否有户籍？如果没有，谁承认他的身份？
3. 他需要服什么役、交什么税？
4. 他若离开当前主家，家属和债务怎么办？
5. 他掌握的技术、兵器或文书属于谁？
6. 他说“忠义”时，具体保护的是谁、哪块地、哪批人？
7. 一场胜利后，土地、人口、牲畜和官位如何重新分配？

> **总判断**：所谓“利益”不只是钱。粮食、身份、保护、婚姻、官位、道路、名分和未来，都可以成为三国时代的人愿意冒险或背叛的原因。
