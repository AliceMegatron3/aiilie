# 三国类似研究 · 东汉历史主线

> **主线范围**：168—220年，必要时上溯东汉中期，下延至280年。
>
> **阅读方法**：每一段按“时间—事件—地点—天时—地利—人和—制度与资源—历史后果”展开。事件栏是史实骨架；“判断”栏是基于多种材料的历史解释；“小说落点”不是史料本身。

---

## 一、总纲：从帝国危机到三国形成

东汉后期的变化可以分成八个阶段：

1. **168—177年：宫廷权力失衡与士人受压**。窦武、陈蕃谋诛宦官失败，党锢扩大；凉州羌乱、鲜卑压力和灾异持续消耗朝廷。
2. **178—183年：财政、灾害和政治合法性同时恶化**。卖官、疫病、地震、蝗灾与宫廷工程并行，太平道在灾民和流动人口中扩张。
3. **184—185年：黄巾起义与大疫**。黄巾主力被镇压，但大批人口脱离原有户籍和土地关系，地方武装获得扩张机会。
4. **186—189年：军事化地方化**。凉州、幽州、并州等边地和内地相继动荡；州牧制度、西园军和地方军政力量上升。
5. **189—192年：董卓、迁都与关中崩解**。洛阳政权失去稳定中心，长安也没有恢复秩序，关中进入军队、饥荒、疫病和流民互相强化的状态。
6. **192—196年：多个军政中心成形**。曹操据兖州并收青州降众，孙策经营江东，刘备不断寻找立足地；献帝流亡后被曹操迎至许。
7. **200—219年：三方竞争的骨架形成**。官渡、赤壁、刘备入蜀、成都易手和汉中争夺，构成魏、蜀、吴三方的地理与资源格局。
8. **220—280年：名义三国与长期统一战争**。曹丕受禅、刘备称帝、孙权称帝，之后魏晋先后灭蜀、灭吴。

### 总因果链

> **灾异与疫病 → 生计破坏 → 破产、逃亡与宗教动员 → 户籍和税收萎缩 → 朝廷财政依赖临时征发与卖官 → 军事支出和边疆战争加剧 → 地方官、豪强和将领掌握兵粮 → 州牧与军阀坐大 → 天子成为合法性资源 → 三国政权竞争。**

这条链不能解释每一个人的选择，但能解释为什么个人野心有了可乘之隙。

## 二、逐段主线

### 阶段一：建宁元年—熹平六年（168—177）

| 项目 | 内容 |
|---|---|
| 时间 | 168—177年，汉灵帝即位前期 |
| 主要事件 | 窦武、陈蕃谋诛宦官失败；曹节等宦官集团掌权；第二次党锢；段颎平羌；蔡邕主持熹平石经；七州蝗；鲜卑犯塞 |
| 核心地点 | 洛阳、太学、凉州、陇右、弘农、三辅、北方边塞 |
| 天时 | 地震、疫病、螟蝗和边地气候压力反复出现；灾异被朝廷解释为政治警告 |
| 地利 | 洛阳依黄河、伊洛和关东粮运维持中心地位；凉州远离核心粮区，军粮与补给成本高；三辅是关中与京师的缓冲地带 |
| 人和 | 外戚、宦官、士大夫三方争权；凉州羌人与汉军、地方豪族反复冲突；太学和党人形成政治声望网络 |
| 制度与资源 | 皇帝通过宦官控制诏令与宫廷；党锢限制士人入仕；边军耗费和征发增加；经学和太学仍是政治文化资源 |
| 历史后果 | 宫廷内部失去相互制衡，士人对朝廷的信任下降；军队和边地事务越来越难由文官体系直接控制 |

**历史判断**：此阶段的关键不是“宦官突然夺权”这么简单，而是皇权借助宦官绕过外戚和士人，短期提高了宫廷控制力，却削弱了可持续的政治协商机制。

**地点调用**：洛阳宫门、太学石经、凉州军营、关中驿道、边塞烽燧。

### 阶段二：光和元年—光和六年（178—183）

| 项目 | 内容 |
|---|---|
| 时间 | 178—183年 |
| 主要事件 | 鸿都门学设立；卖官制度化；蔡邕因天变上书获罪；连续大疫；朝廷修宫聚财；三辅、关中和各地灾荒；张角太平道传道并筹划甲子起事 |
| 核心地点 | 洛阳、西邸、鸿都门、三辅、关中、冀州、颍川、南阳、青州、幽州、益州北境 |
| 天时 | 179、181、182年均有大疫记载；此前已有地震、蝗灾和旱灾背景；地方灾情不必等到全国同样严重才产生流民 |
| 地利 | 冀州、豫州、颍川和南阳人口、交通、农产密集，既便于传教也便于起兵；三辅连接关中和凉州，受战争与灾荒双重冲击；益州由山川和蜀道隔开，成为流民想象中的避难地 |
| 人和 | 破产农民、太平道信徒、地方小吏、乡里豪强和朝廷官军逐渐分化；士大夫批评宦官和宫室工程，但难以改变财政结构 |
| 制度与资源 | 田租、算赋、口赋、更赋和临时加派叠加；卖官使官职具有直接货币价格；朝廷以工程和军费消耗财富，地方以催科和借贷转嫁压力 |
| 历史后果 | “灾害—疾病—赋税—逃亡”形成循环；太平道把分散的生存困境转化为跨地域组织和政治口号 |

**史实边界**：183年秋三辅—汉中交界的连年旱蝗是本项目的艺术设定，不能写成《后汉书》明确记载的全国性灾异；可用前后多年蝗灾、疫病和地方灾荒作为背景。

**小说落点**：一粒谷种、一次催租、一张卖身契、一道西邸文书，都可以让宏观危机落到人物身上。

### 阶段三：中平元年—中平二年（184—185）

| 项目 | 内容 |
|---|---|
| 时间 | 184年二月起义，至185年 |
| 主要事件 | 黄巾起义；皇甫嵩、朱儁、卢植、曹操、孙坚等镇压；张角病死、张梁张宝战死；黄巾主力溃败；185年春大疫；三辅螟蝗；灵帝征天下田亩十钱、铸铜人 |
| 核心地点 | 冀州广宗、下曲阳；颍川长社；南阳宛城；青徐兖豫等地；洛阳；三辅；蜀道和益州北部 |
| 天时 | 春季青黄不接，起义与流民潮叠加；184年大规模流动导致疾病传播；185年正月大疫，七月三辅螟蝗 |
| 地利 | 广宗、宛城、颍川是人口和交通节点；黄河、汝水、淮水和道路影响军队机动；益州有蜀道障碍，也有成都平原、盐铁和水利资源 |
| 人和 | 太平道徒众、地方豪强、郡国兵、朝廷中央军、流民和降卒交错；朝廷能消灭主力，却未能恢复原有生计与户籍秩序 |
| 制度与资源 | 解除党锢以争取士人支持；中央临时调兵；战后降卒、流民和土地的安置成为地方问题；税亩十钱进一步增加压力 |
| 历史后果 | 黄巾作为军事主力被击败，但其造成的组织遗产、人口流动、地方武装化和朝廷财政危机延续；“平叛”没有等于“复原” |

**关键判断**：黄巾不能只写成“迷信煽动”，也不能只写成“纯粹农民革命”。它同时具有宗教组织、灾民互助、反税役、地方武装和政治起义的多重性质。

**人物年龄红线**：184年时曹操已有军职和军功；刘备尚处早期起兵阶段；诸葛亮年幼，不能提前参与核心政治。

### 阶段四：中平三年—中平五年（186—188）

| 项目 | 内容 |
|---|---|
| 时间 | 186—188年 |
| 主要事件 | 四出文钱；凉州韩遂、边章等起兵；董卓参与凉州战事；幽州、并州等地动荡；刘焉建议“废史立牧”；刘焉任益州牧；西园八校尉设置 |

| 地利 | 凉州与关中之间是军事走廊；幽州连接北方草原与河北；益州山川封闭，内部平原富庶；汉中是益州北门 |
| 人和 | 边军将领、地方豪族、羌胡部落、流民、宗室州牧和宫廷军队各自积累自主力量；朝廷希望用州牧和西园军重新控制局面，实际上给地方和军队增加了合法名义 |

**时间红线**：188年前写益州长官应使用“刺史”；刘焉任益州牧、东州流民军事化等内容必须放在188年以后。

## 三、地点主线：四个相互牵动的空间

### 1. 洛阳—关中轴

- 洛阳：宫廷、太学、官署、仓储、交通和政治合法性的集中点。
- 三辅：京兆、左冯翊、右扶风，连接洛阳、关中和凉州；既是粮食与人口缓冲区，也是灾荒和战争重灾区。
- 长安：西汉旧都和关中政治中心；董卓迁都后承担天子、百官和西凉军的临时秩序，但供粮能力不足。

### 2. 凉州—河西—北方边塞轴

- 凉州：军费高、边疆压力大、羌汉关系复杂；长期战事塑造了擅长骑战和军政的地方集团。
- 河西：通向西域，商业与军政兼具；道路和水源决定城镇生存。
- 并州、幽州：连接草原与中原，乌桓、鲜卑、南匈奴和汉地军政集团在此互动。

### 3. 汉中—蜀道—益州轴

- 汉中：益州北门，兼有粮仓、军镇、宗教组织和山地交通功能。
- 褒斜道、金牛道、米仓道、阴平道：不同路线连接关中、汉中、巴蜀与陇右；道路本身就是军事资源。
- 成都平原：水利、粮食、织锦、盐铁和人口构成益州的经营基础。

### 4. 荆州—长江—江东轴

- 荆州：北接中原，西连益州，南通交州，东下江东，是三方都想控制的中间地带。
- 长江：不仅是天然屏障，也是粮食、兵员、商旅和军队的运输通道。
- 江东：吴郡、会稽等地依托水网和地方大族形成区域政权；孙氏需要把军事集团与地方社会结合起来。

## 四、主线的一句话版本

> 东汉后期，宫廷以宦官和临时征发维持权力，边疆战争与灾害疫病不断消耗财政；土地、户籍和税役压力把农民推向流动与宗教组织，黄巾起义击穿了地方秩序，却没有建立新的统一秩序；地方官、豪强和将领因此接管兵粮与人口，董卓时代摧毁洛阳中心，曹操、刘备、孙氏在不同地理资源上重建军政国家，东汉由此转化为三国竞争。
