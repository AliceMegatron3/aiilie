# 底层民众 · 自耕农与流民人设模板

> **物质基础**：田租三十税一但杂派无度、亩敛十钱、算赋120钱、口赋、更赋；亩产一石半，一户五口需年食约十五石；灾年官府照收，谷种即命根。见分卷01天时、03人和、04制度。
>
> **本篇三个模板**：自耕农之女、老年流民、逃奴。每个模板含出生、成长小事、维度分配、维度演化、语言样本、命运终局。

---

## 模板一 · 自耕农之女「阿禾」

### 一、出生与家世（延熹九年，166年）

生于三辅一个五口自耕农之家，有田二十亩，属"中家"下等。父在，母在，一兄一妹。出生那年家里刚还完一笔粟米债。

按东汉习俗，女婴出生第三日"三朝"洗浴，家人不敢多备礼，只煮了一碗稀粥。父亲给她起名"禾"，因为那年谷子长得还行。

**初始情绪分配（幼年，166-172年）**

| 维度 | 值 | 依据 |
|---|---|---|
| E1喜 | 6 | 家有田，父母在，幼年有稳定饱食 |
| E2怒 | 4 | 家教顺从，女孩不许争论 |
| E3哀 | 4 | 未遭大丧 |
| E4惧 | 5 | 知道乡吏可怕，但家有田不至于恐慌 |
| E5爱 | 7 | 有完整家庭，依附父母兄妹 |
| E6恶 | 6 | 家教有基本是非 |
| E7欲 | 4 | 女孩不被鼓励有目标 |
| D1食欲 | 5 | 未饿过 |
| D2色欲 | 3 | 年幼未及 |
| D3利欲 | 4 | 懂钱但不执念 |
| D4名欲 | 5 | 在乎"人家怎么说"，村落舆论压力 |
| D5生欲 | 6 | 正常 |
| D6权欲 | 2 | 女孩无掌控预期 |

### 二、成长小事与维度变化

**七岁（172年）· 第一次跟去交租**
乡吏的秤杆压得低，一石算九斗。父亲不吭声，把多的一斗补上。回家路上，父亲一句话没说。
→ **E4惧 5→6**（认识到权力不可抗）；**E2怒 4→5**（第一次感到不公）

**十岁（175年）· 看着邻家女孩被插草标卖掉**
那女孩比她大两岁，被牵走时没哭。母亲把她拉回屋里，说"别看"。
→ **E4惧 6→7**；**D4名欲 5→4**（"体面"开始变成奢侈品）

**十二岁（177年）· 学纺织，第一次挣到钱**
她织的布卖了三十钱，母亲把钱藏进梁缝。她第一次知道自己能创造价值。
→ **E7欲 4→5**；**D3利欲 4→5**

**十六岁（181年）· 议亲未成**
对方要五千钱聘礼，家里拿不出。事情作罢，她被村里议论"没人要"。
→ **D4名欲 4→6**（羞耻感强化）；**E3哀 4→5**；**D2色欲 3→5**

**十七岁（182年）· 连年旱开始**
田裂，蝗虫来了。父亲一天去田里三趟。粮价从三十钱涨到八十钱。
→ **D1食欲 5→7**（身体开始记住饥饿）；**E4惧 7→8**

**十八岁（183年秋）· 卖地**
父亲卖了十五亩地给乡里豪强，价钱是市价一半。她看着契书上父亲按下的朱红手印。
→ **E2怒 5→7**（明确知道被剥夺）；**E1喜 6→4**；**E7欲 5→6**（开始想"要变"）

**十八岁（183年冬）· 兄自卖为奴**
兄为让全家活下去，自卖入豪强家。奴婢律比畜产，倍算240钱。她送兄到门口，兄没回头。
→ **E3哀 5→7**；**E5爱 7→8**（对家人依附更深）；**D5生欲 6→7**

**十九岁（184年春）· 青黄不接**
去年秋粮吃尽，新麦未熟。全村吃树皮、草根。公灶开始分粥。她饿到看东西发花。
→ **D1食欲 7→9**；**E1喜 4→2**；**E4惧 8→9**

**十九岁（184年春末）· 公灶变味**
一个无月之夜，公灶的火比往常旺，锅里有肉。她闻出来了。
→ **E6恶 6→9**（道德冲击，无法接受）；**D5生欲 7→8**；**E1喜 2→1**；**E7欲 6→8**（必须走）

### 三、184年春末的最终分配

| 维度 | 值 | 外显 |
|---|---|---|
| E1喜 | 1 | 不笑，不回应笑；被问好话不知如何应答 |
| E2怒 | 7 | 内压式愤怒，手会握紧，但不出声 |
| E3哀 | 7 | 提到兄和地会停顿很久 |
| E4惧 | 9 | 听见马蹄先找藏身处；见到穿好衣的人先低头 |
| E5爱 | 8 | 会把最后的饼给别人；提"我们村"时声音变化 |
| E6恶 | 9 | 拒绝吃某些东西，宁死不吃；对某几个人再不说话 |
| E7欲 | 8 | 会计划，会记路，会问哪里有活路 |
| D1食欲 | 9 | 随时摸腰间；把谷种缝在衣里；见食物先算能吃几天 |
| D2色欲 | 4 | 亲密需求被生存压下 |
| D3利欲 | 5 | 只关心能换粮的东西 |
| D4名欲 | 3 | 已放弃体面，可以乞讨 |
| D5生欲 | 8 | 会跑，会藏，会说谎保命 |
| D6权欲 | 3 | 尚无掌控欲，但开始想"要是我能定就好了" |

### 四、语言样本（矩阵：压抑型转蓄力型）

**对官吏（E4惧9主导）**
> "是。小的知道。"
> "小的这就走。"

**对同路流民（E5爱8+D1食欲9）**
> "你先吃。"
> "别往那边，那边的水是黄的，喝了要泻。"

**独处或对信任者（E2怒7+E6恶9压出来）**
> "我不吃那个。"
> "我看见了。那锅里的东西，我看见了。"
> "地是我爹的。三十亩，卖了十五亩，换了四石粮。四石粮，吃了两个月。"

**规划（E7欲8）**
> "往南。听说益州不收人头税。"
> "先找水，再找人，人多的地方有粥棚。"

### 五、可能的命运走向

- **走向A（E7欲继续升，D4名欲低）**：入豪强庄园为佃户，靠会织布、识些字被用；184-185年可与阿雅、阿玉线交汇。
- **走向B（E6恶9不肯妥协）**：拒绝进吃过人的收留点，独行，死于184年夏疫。
- **走向C（D5生欲升到9，E6恶被压到4）**：成为庄园的告密者，活得比谁都久，但E1喜永久锁死在1。

## 模板二 · 老年流民「老邴」

### 一、出生与前半生（永建三年，128年）

生于凉州边郡自耕农家。少年时经历羌乱三次，四十岁前搬过四次家。有过妻，有过三个孩子；到183年，妻死于疫，长子死于兵，次子失散，女儿卖了。

他今年五十五岁，在东汉属高寿。他记得的年号比大多数人记得的多。

### 二、维度分配（183-184年，五十五岁）

| 维度 | 值 | 依据 |
|---|---|---|
| E1喜 | 2 | 一生所失过多，快乐机制基本关闭 |
| E2怒 | 2 | 愤怒早已烧完；知道愤怒无用 |
| E3哀 | 6 | 有哀但已成常态，不再剧烈 |
| E4惧 | 4 | 见过太多，恐惧阈值高；知道什么真危险什么不 |
| E5爱 | 5 | 家人都没了；对陌生人有一种散漫的善意 |
| E6恶 | 5 | 见过吃人，不评判，但自己不做 |
| E7欲 | 3 | 无长远目标，只走一天算一天 |
| D1食欲 | 6 | 饿惯了，反而不慌；胃已经小了 |
| D2色欲 | 2 | 无 |
| D3利欲 | 3 | 不攒；有了就分 |
| D4名欲 | 2 | 早无体面可言 |
| D5生欲 | 4 | 不特别求生；"哪天倒了就倒了" |
| D6权欲 | 3 | 不想管事，但会被年轻人问路 |

### 三、这套配置的独特功能

老邴是**低欲高知**型。他不谋划，但他知道：哪条路有水、哪个季节走哪条道、羌人怎么打、官军怎么征粮、瘟疫的先兆是什么、什么草能吃什么不能。

- **E4惧只有4**：他能在别人恐慌时平静说"没事，那是自家的牛叫"。
- **E7欲只有3**：他不会推动情节，但他会在关键处给一句话。
- **D5生欲只有4**：他可以在必要时留下断后，因为他真的不特别怕死。

### 四、语言样本（矩阵：低欲叙事者型）

**功能性提示（低感情，纯经验）**
> "那水不能喝。上游有死东西。"
> "过了那道岗，就是汉中的地界了。"
> "这天不会下雨。云是散的。"

**回忆（E3哀6，但节制）**
> "我这辈子搬过四回家。头一回是延熹年间，羌人来了。"
> （被问家里人）"没了。"

**对死亡（D5生欲4）**
> "我这把年纪了，倒在哪儿都一样。你们走。"

### 五、命运终局

184年夏疫中病倒，主动要求被留下，不拖累同行者。若被救，则在185年成为庄园里教农事和辨草药的老人——他的经验值远高于他的行动力。

写作功能：他是"历史记忆的载体"，靠他一个人的话，读者能感到东汉已经烂了几十年，不是突然崩的。

## 模板三 · 逃奴「铁头」

### 一、出生与来历（熹平二年，173年）

生于豪强家的奴产子——父母都是奴婢，他生下来就是奴。按律，奴婢比畜产，主人可以买卖、责打。他没有姓，只有"铁头"这个名，因为小时候被打头不哭。

十一岁（184年）灾年，主人为省粮"放"了一批老弱奴婢——放不是恩典，是抛弃。他跟着跑了。

### 二、维度分配（184年，十一岁）

| 维度 | 值 | 依据 |
|---|---|---|
| E1喜 | 3 | 从未有过快乐的稳定来源；但年幼，还有恢复余地 |
| E2怒 | 8 | 十一年的挨打积成了怒；且年幼未学会压 |
| E3哀 | 3 | 从不曾拥有，所以谈不上失去 |
| E4惧 | 6 | 怕打，但打惯了；怕的是特定人、特定声音 |
| E5爱 | 3 | 父母也是奴，无力护他；未建立依附 |
| E6恶 | 4 | 无人教是非；道德边界靠痛感建立 |
| E7欲 | 7 | 强烈"不要回去"的驱动 |
| D1食欲 | 8 | 常年半饱 |
| D2色欲 | 2 | 年幼 |
| D3利欲 | 6 | 极重视自己拿到手的东西，会藏 |
| D4名欲 | 1 | 无体面概念；被骂无反应 |
| D5生欲 | 9 | 唯一确定的信念：活着 |
| D6权欲 | 5 | 隐藏的高值——他非常想有一天不被人管 |

### 三、这套配置的行为特征

**E2怒8 + E4惧6 + D4名欲1**的组合极为危险：他不在乎被人怎么说，被逼时敢动手，但见到旧主人的旗号会立刻僵住——他的恐惧是**具体的、有形象的**，不是弥散的。

**E6恶4**：他会偷。他不认为偷是错的，因为他从来没有过属于自己的东西。这里要写清逻辑，不要写成天然坏人。

**D6权欲5（隐藏）**：他会在流民群里悄悄形成小圈子，替人出头换食物。这是他第一次尝到"被需要"的滋味。

### 四、语言样本（矩阵：蓄力型幼年版）

**极短，多为动词句**
> "给我。"
> "不去。"
> "他打人。"

**被问身世（D4名欲1，毫无避讳）**
> "我是奴。放出来的。"

**愤怒时（E2怒8）**
> "你再动一下。"

**唯一的柔软处（E5爱3但正在生长）**
> （对给他饼的人，隔很久）"……你吃了吗。"

### 五、维度演化路径

**若被善待（E5爱3→7）**
185-186年成为坞堡部曲，忠诚度极高——因为他一生第一次被当人对待。E2怒8会转为战斗力，E6恶4会随教育升到6。

**若继续被利用（E5爱锁在3，E6恶降到2）**
成为豪强的私兵中最狠的一个。D6权欲5→8，最终背叛任何人。

**若被抓回（D5生欲9受挫）**
被处死或致残；这条线是给读者看"逃是要付代价的"。

### 六、写作提示

铁头这个模板的价值在于：他把"奴婢律比畜产"这条冷冰冰的制度，变成一个十一岁孩子的说话方式。不要让他讲道理，让他的短句本身成为控诉。
