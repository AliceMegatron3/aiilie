# 自建人设操作流程与核验表

> **本文功能**：给出从零生成一个新人物的七情六欲配置的十步流程，以及成稿前的核验清单。前六篇是成品模板，本篇是造模板的方法。

---

## 一、十步生成流程

### 第1步 · 定阶层与年份

先确定两件事：这个人物在哪一年出场，属于哪个阶层。

阶层决定初始分配的重心（见04文档末尾的阶层对照表）：
- 底层：D1食欲高，D4名欲低，E4惧的对象是饿死
- 中间层：D3利欲高，E4惧的对象是失去位置
- 上层：D4名欲与D6权欲高，D1食欲低，E4惧的对象是失位失族
- 缝隙群体：D5生欲高或极低，不在名册内

### 第2步 · 查该年份的物质条件

打开 `融合/历史资料/00-索引与调用.md` 的时间线主索引，取该年该季的粮价、灾情、赋税、战况。

**这一步不能跳。** 一个184年春的人物和一个186年秋的人物，即使同阶层，D1食欲也差2到3。

### 第3步 · 填十三个初始值

按第1、2步的结论填表。填的时候遵守三条：
- 不要全填5到7，那会造出一个没有性格的人。
- 至少有一个维度≥8，那是他的主导驱动。
- 至少有一个维度≤3，那是他的盲区或残缺处。

### 第4步 · 找出这个配置的核心张力

在十三个值里找一对**互相冲突的高值**，那就是这个人物的全部戏剧性来源。

已有模板的核心张力示例：
- 阿禾：D1食欲9（要活）vs E6恶9（不肯那样活）
- 石三：E6恶4（听命令）vs E5爱6（护兄弟）
- 魏五：D3利欲9（有钱）vs D4名欲7（没地位）
- 荀婉：E6恶8（能判断）vs D6权欲4（无处施展）
- 田氏：E5爱10（为孩子）vs D5生欲8（想活）

**没有核心张力的人物不要写进正文，只能当背景人物。**

### 第5步 · 反推成长小事

从初始值倒推：这个值为什么是这个数？每个偏离中间值（5-6）的维度，都要有一件具体的事作为来源。

- D1食欲9 → 哪一年饿的？饿了多久？
- D4名欲2 → 什么时候第一次跪下的？
- E5爱10 → 除了这个人，其他的都怎么没的？
- E6恶3 → 是谁教他"这样也行"的？

**写三到八件小事，按年份排列。** 每件事只需一两句，但必须有具体物件（秤杆、草标、契书、锅、名册）。

### 第6步 · 定语言风格

查01文档第四节"语言风格与维度关系速查"，把高值维度对应的语言特征组合起来。然后加两条限制：

1. **句子长度**：E4惧高、E1喜低的人说短句；E1喜高、E7欲高的人说长句。
2. **词汇范围**：查 `更细化物质研究/05-汉人文字表现与语言用法.md`，确认该阶层能用的自称、称谓、成语和典故。士族可以用典，佃农不能。

### 第7步 · 写四组语言样本

固定写这四种情境，因为它们能覆盖大部分场景：

1. **对上位者说话**（测E4惧和D4名欲）
2. **对同类说话**（测E5爱和E1喜）
3. **独处或对最信任的人**（测E2怒和E3哀的真实值）
4. **他的专业领域**（测E7欲，也是他最有魅力的时刻）

### 第8步 · 挂上历史事件

查06文档的漂移表，把该人物从出场年份推到全书结束年份，标出每个事件的维度变化。

**重点标出两个时刻**：
- **崩溃点**：哪个事件会让他的核心维度失效？（田氏是孩子死，陶叟是炉毁，李阿婆是信仰被证伪）
- **转机点**：什么条件能让他的低值维度回升？（郭犬子是有饭有名册，铁头是被当人对待）

### 第9步 · 写三条命运走向

不要只写一条。至少写三条，标注触发条件：
- 一条上升（某维度被点亮）
- 一条持平（活着，但内部锁死）
- 一条下坠（核心维度崩塌）

**理由**：写作时情节会变。三条走向让人物在任何情节下都不会失真。

### 第10步 · 写一句"写作功能"

用一句话说清：这个人物在小说里承担什么不可替代的作用？

如果写不出来，或者和已有人物重复，那就该合并或删掉。

## 二、常见错误与修正

| 错误 | 症状 | 修正 |
|---|---|---|
| 全维度中间值 | 人物无个性，说话像旁白 | 强制拉出一个≥8和一个≤3 |
| 道德与阶层重合 | 穷人都善良，富人都恶 | E6恶按"两端高中间低"曲线分配，执行层最低 |
| 数值与行为脱节 | 标了E2怒8，但全程温和 | 每个≥7的维度必须在正文里兑现至少两次 |
| 只涨不落 | 人物越写越强 | 用06文档的漂移表，让维度双向变化 |
| 用后世词汇 | 底层人物讲现代逻辑 | 查更细化物质研究05，逐句核语言 |
| 情绪直说 | "她感到非常悲伤" | 改为器物与动作，见著作技巧03的六种借景结构 |
| 苦难堆砌 | 一个人物承受所有惨事 | 分散到多个人物，各承担一种制度成本 |
| 高维度无代价 | E5爱10只有优点 | 兑现高分代价，见01文档各维度末的代价说明 |

## 三、成稿前核验表

### 配置层

- [ ] 十三个维度都填了值，且不是清一色5-6？
- [ ] 有至少一个≥8的主导维度？
- [ ] 有至少一个≤3的残缺处？
- [ ] 找出了核心张力（一对冲突的高值）？
- [ ] 每个偏离中间值的维度都有具体来源事件？

### 历史层

- [ ] 出场年份的粮价、赋税、灾情与时间线主索引一致？
- [ ] 没有出现该年份之后才有的制度（州牧、东州兵、建安大疫）？
- [ ] 阶层身份符合利益结构文档（自耕农、徒附、部曲、奴婢、市籍的区别）？
- [ ] 涉及史实人物或事件时，查过分卷10的史料分层？

### 语言层

- [ ] 自称、称谓、语体符合该阶层？（小的/下吏/婉/仆）
- [ ] 句子长度与E4惧、E1喜的值匹配？
- [ ] 没有现代词汇（经济、项目、信息、效率）？
- [ ] 没有宋代及以后的词（菜人、两脚羊）？
- [ ] 用典范围符合其识字程度？

### 表现层

- [ ] 每个≥7的维度在正文里兑现了至少两次？
- [ ] 情绪是靠器物、动作、沉默呈现的，不是靠形容词？
- [ ] 高值维度的代价写出来了？
- [ ] 有一个专属物件反复出现（谷种、账本、锤、符、名册）？
- [ ] 崩溃点和转机点都设计了？

### 结构层

- [ ] 写出了三条命运走向及触发条件？
- [ ] 写作功能一句话说得清，且不与已有人物重复？
- [ ] 与主线人物（阿雅、阿玉、阿俊、荆安）的关系与差异明确？
