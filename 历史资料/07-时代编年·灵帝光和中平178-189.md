# 《乱世双璧》历史资料库 · 分卷07：时代编年② 汉灵帝·光和—中平（178—189）

> **对应小说时间**：第1章（光和六年183秋）至第14章（中平二年185春）直接背景，以及此后2-4卷时代底色。
> **关键词**：卖官鬻爵、黄巾起义、张角、皇甫嵩、朱儁、卢植、董卓、曹操、刘备、孙坚、段颎、党锢解除、刘焉、废史立牧、西园八校尉、张让、十常侍、何进
> **本卷定位**：灵帝后期朝局崩溃→黄巾起义→诸侯萌芽，小说1-4卷的核心历史舞台。

---

## 一、光和年间（178—184）——朝局糜烂，民间酝酿

### 光和元年（178）

- **二月**：始置**鸿都门学**（灵帝好辞赋书画，招能为尺牍、辞赋者充之），与太学对立。
- **春**：京师地震。
- **张让、赵忠**等共构宋皇后（宋氏），灵帝废杀之。宦官势力膨胀至顶。
- ⚠️ 张让年表：桓帝时为小黄门，灵帝时升中常侍，封列侯。

### 光和二年（179）

- 春，**大疫**。灵帝遣中谒者巡行致医药（《后汉书·灵帝纪》）。
- ⚠️ 第14章《疫》可参考此动作，写"朝廷也派人来，但人还没到，病的人已经埋了"。

### 光和三年（180）

- 灵帝设**西邸**卖官，二千石二千万钱、四百石四百万钱（《山阳公载记》）。
- 九月，日食。**蔡邕**因天变上书论灾异，被宦官构陷，流放朔方。
- 十月，诏举贤良方正一人。蔡邕虽被流放，但士林声望愈高。
- 十月，改立何氏为皇后（何皇后，何进之妹）。

### 光和四年（181）

- 秋，**大疫**。灵帝遣中谒者巡行致医药。
- 七月，**刘宏造万金堂**，聚天下金银财物。
- ⚠️ 曹操年表：约此年，曹操为洛阳北部尉，用五色棒杀宦官蹇硕叔父蹇图——初露刚直。

### 光和五年（182）

- 春，**大疫**。朝廷再遣中谒者致医药（连续三年大疫）。
- ⚠️ 灵帝朝见于《后汉书》的大疫有171、173、179、182、185年，几乎隔年一次。

### 光和六年（183）——★小说起点

- **秋**：三辅/汉中旱蝗连年（艺术设定，有熹平六年七州蝗打底）。
- 此时张角"苍天已死，黄天当立，岁在甲子"已在青徐幽冀荆扬兖豫八州秘密传道。
- **曹操**：任东郡太守，征黄巾后迁济南相（后辞官归乡，184年被征拜骑都尉）。
- **刘备**：约此年织席贩履于涿郡，与关羽、张飞相识（桃园结义传说，史实无明载）。
- **荀彧**：颍川颍阴人，约此年被举孝廉（王朗传"荀彧年少时，王朗知其才"），官拜守宫令。颍川荀氏为当地名族。
- **诸葛亮**：琅琊郡阳都人，此年尚幼（181年生，此时2岁）。其父诸葛珪为泰山郡丞。

### 光和七年（184） = 中平元年——★黄巾起义

| 时间 | 事件 | 关键人物 |
|---|---|---|
| **二月** | ★黄巾起义爆发。"苍天已死，黄天当立，岁在甲子，天下大吉"；八州响应。 | 张角（冀州）、波才（颍川）、张曼成（南阳） |
| **三月** | 灵帝大赦党人（解除党锢16年）。下诏镇压。 | 皇甫嵩奏请解除党禁，中常侍吕强附议 |
| **四月** | **左中郎将皇甫嵩、右中郎将朱儁、骑都尉曹操**率兵四万讨颍川黄巾。 | 波才大败朱儁，围皇甫嵩于长社 |
| **五月** | 皇甫嵩火攻波才，大破颍川黄巾。**孙坚**募兵千余人助朱儁。 | 皇甫嵩封都乡侯，曹操迁**济南相** |
| **六月** | 张曼成攻杀南阳太守褚贡。南阳黄巾以赵弘为帅，众十余万据宛城。 | 朱儁进围宛城 |
| **八月** | 卢植围张角于广宗，因拒贿赂小黄门左丰，被诬下狱。**董卓**代卢植攻广宗，不胜。 | 董卓罢职 |
| **十月至十一月** | 皇甫嵩代董卓，大破广宗张梁（张角已病死），斩首三万，溺死者五万。进击下曲阳破张宝，斩首十余万，筑"京观"。 | 皇甫嵩封左车骑将军、领冀州牧、槐里侯 |
| **十二月** | 南阳黄巾赵弘被杀，朱儁平宛城。颍川、汝南、陈国三地黄巾基本平定。 | 黄巾主力九个月内被消灭 |

### 张角生平

- 巨鹿人，创太平道，以符水治病传道。约十余年，徒众数十万。分三十六方（军事单位），大方万余人，小方六七千。约183年策划"甲子年"起义。184年病死军中。弟张梁、张宝同年战死。

### 卢植生平

- 涿郡涿县人（刘备同乡，可能有师承关系）。大儒，马融弟子。黄巾时为北中郎将讨冀州，因不肯行贿太监左丰被下狱。后平定黄巾余部。董卓之乱时为大儒名臣代表。

## 二、中平年间（185—189）——朝廷最后挣扎

### 中平二年（185）

- **春正月**：★★**大疫**（《后汉书·灵帝纪》）→ **第14章《疫》直接史实**。
- **七月**：三辅螟蝗（《后汉书·灵帝纪》）→ 第15-16章守庄环境背景。
- 灵帝"税天下田亩十钱"，以修宫室、铸铜人。造**铜人**四列于宫门外。
- 赵忠、夏恽等共谮皇甫嵩，嵩被罢左车骑将军，削户六千。皇甫嵩功高被抑，寒心。

### 中平三年（186）

- 段颎为司隶校尉，宦官段颎与王甫等勾结。后王甫被段颎诛杀（宦官内斗）。
- 江夏蛮复叛，州郡击破之。
- 灵帝铸**四出文钱**（钱质恶劣，民不乐用）。

### 中平四年（187）

- 二月，荥阳民数千人起事。韩遂、边章攻凉州，杀凉州刺史耿鄙，陇右大乱。**董卓**随张温讨凉州叛军。
- **公孙瓒**与乌桓战于辽西。刘备随公孙瓒。
- 张纯、张举叛于幽州，自称天子，乌桓叛应。

### 中平五年（188）——★关键转折年

| 时间 | 事件 | 历史意义 |
|---|---|---|
| **三月** | 太常刘焉建议"废史立牧"，以宗室为州牧。 | **州牧制开端**——地方割据合法化。⚠️188年前益州长官写"刺史" |
| **三月** | 刘焉为监军使者、益州牧。入蜀，收编**东州兵**。 | 益州从此进入刘焉时代 |
| **三月** | 南匈奴屠各叛，并州刺史张懿被杀。 | 并州开始失控 |
| **八月** | 灵帝设**西园八校尉**，小黄门蹇硕为上军校尉，大将军何进亦须受其节制。 | ⚠️ 袁绍为中军校尉，曹操为典军校尉 |
| **十月** | **郭泰**于白波谷起兵（白波贼）。 | 益州、并州开始失控 |
| **十一月** | 刘焉改任**益州牧**。 | 刘焉开始经营蜀中，益州进入新阶段 |

### 中平六年（189）——灵帝崩，天下大乱

| 时间 | 事件 | 关键人物 |
|---|---|---|
| **四月** | ★灵帝崩，年三十三。葬文陵。大将军何进立皇子辩（少帝）。 | 何进掌权 |
| **五月** | 何进杀蹇硕。大赦天下，追废董太后（刘协母）。 | 外戚vs宦官最后博弈 |
| **六月** | 何进谋诛宦官，犹豫不决。召外兵入京。 | 董卓、丁原、苗等 |
| **八月** | 何进被**张让、赵忠**等十常侍伏杀。袁绍率兵尽诛宦官两千余人。 | 东汉宦官政治终结 |
| **九月** | **董卓**率西凉兵入洛阳，废少帝立陈留王刘协（献帝），杀何太后。 | **董卓专权**，天下群雄割据开始 |
| **九月** | 董卓追派使者吊祭陈蕃、窦武，为党锢受害者平反。 | 距陈蕃被杀已22年 |
| **十一月** | 董卓自为太师，位在诸侯王上。 | 董卓权倾天下 |
